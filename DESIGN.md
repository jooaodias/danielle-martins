# Design System — Danielle Martins

## Visual World
**Human Cobalt Editorial** — Inspired by personal creative websites (tactile photo framing, expressive display type, kinetic marquee) and People-leader portfolios (clear impact narrative, real career chapters, frictionless contact). Anchored in vibrant royal cobalt (`#16429B` / `#2563EB`), soft sky (`#EAF2FF`), and bright daylight (`#FAFBFD`).

## Typography

- **Display:** `Bricolage Grotesque` (weights 600, 700, 800), self-hosted via `@fontsource/bricolage-grotesque`.
- **Body:** `Source Sans 3` (weights 400, 500, 600), self-hosted via `@fontsource/source-sans-3`.
- **Personal Annotation:** `Caveat` (weight 600), self-hosted via `@fontsource/caveat`, used sparingly on Danielle's photo caption and quote signature.
